# 后台创建用户邮箱

用户确认在当前创建新用户窗口手动增加邮箱。保留手机号及现有必填规则，邮箱为选填；填写时校验格式。提交原生 RegisterUserInfo.email，通过现有 /user/import/json 和共享 RegisterUser RPC 写入 attribute.email、credential 邮箱登录凭据，与个人注册相同。无需新数据库或后端接口。

官方管理前端仅以固定版本镜像部署，仓库无前端源码。用可读脚本对固定版本用户列表 bundle 定点补入 Ant Design Form.Item 和 payload 字段，构建派生镜像；遇到上游结构变化构建报错。保留原版其余组件。

验证格式错误阻止提交、真实创建独立用户、邮箱密码登录成功、重复邮箱拒绝且无重复用户。仅测试用户会持久化，已告知用户。部署只重建管理网页容器，保留监控及 IM/Chat 服务。
