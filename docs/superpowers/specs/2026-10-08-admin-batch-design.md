# 后台批量创建用户

用户已授权把原生账号创建功能接到后台按钮，包含逐条结果及避免成功项重试。业务用户列表增加“批量创建用户”；提供多行填写/粘贴，格式为昵称、邮箱、手机号、密码（Tab 分隔），邮箱必填，手机号选填（+86），每次最多50条。创建前解析、格式验证及批内重复邮箱/手机验证。密码不进入结果表、不持久化浏览器存储。

原生 /user/import/json 逐个创建但中途出错只返回第一个错误。为显示准确逐条结果，逐条调用已有 /chat/account/register 管理员注册入口，与个人注册共用字段及手机号预留唯一约束，且返回 userID。使用现有管理员 token 和 MD5 密码协议，不修改后端。成功项不会重复提交；网络异常项停止剩余队列，标记结果待确认并提示查看用户列表。已提交的整批锁定，只有新建批次才可输入新资料，不提供盲重试。

基于现有官方前端派生镜像，在用户列表工具栏插入 React 组件，使用原组件 React、request 和刷新表格回调。单独可读 JS/CSS 随镜像部署。保留单用户创建窗口和邮箱补丁。部署仅 admin。验证两账号真实创建及登录、批内重复拦截、原生重复账号拒绝、逐条结果、不重复提交成功项及不确定网络结果停止。
