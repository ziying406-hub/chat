# 99chat PWA 完善

用户已选择 PWA 作为手机方案，沿用现有手机布局和 OpenIM Web SDK，不新建原生应用。现有安装清单引用不存在的 PNG 图标，iOS 图标指向 SVG，页面缓存优先导致旧版残留。

补齐蓝底白色聊天图标的 192/512 PNG 和 iOS 180 PNG，使用 99chat 名称、稳定应用 ID、standalone 模式和 messages 启动路由。已有会话打开聊天，未登录由现有路由返回邮箱登录。删除不存在的定制启动图引用。

保留 Chromium 原生安装事件，iOS 浏览器显示 Safari 分享→添加到主屏幕的指导；独立模式不显示安装提示，安装完成后收起提示。

Service Worker 仅缓存同源静态 GET 请求；文档导航和应用配置在线优先、断网回退，带版本名的构建资源和 WASM 缓存优先。POST、API 与外域请求交给网络，避免缓存用户数据。保留现有独立 FCM worker。首次安装不提示“新版本”，实际更新才提示刷新。

验证安装清单与图标真实有效、Chromium 安装资格、iOS 指导/独立模式、页面手机宽度、离线重开以及在线新版本读取。桌面浏览器测试不能替代真实 iPhone/Android 的系统安装与后台通知测试；本次不宣称完成后台通知送达。
