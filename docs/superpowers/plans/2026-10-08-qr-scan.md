# 扫一扫 Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task.

**Goal:** 点击扫一扫打开真实扫码器，扫描名片后确认发送好友申请。
**Architecture:** 独立 ScanContact 弹窗负责摄像头、图片解码和资料确认。
FriendRequests 挂载弹窗；原生 SDK 负责 getUsersInfo 和 addFriend。
**Tech Stack:** React、TypeScript、qr-scanner 1.4.2、OpenIM Web SDK。

## Global Constraints

- 仅接受已存在的 99chat:user:<userID> 格式，不自动发送好友申请。
- 关闭弹窗后释放摄像头；相册识别不依赖摄像头权限。
- 保留其他好友申请列表、名片、分享操作。
