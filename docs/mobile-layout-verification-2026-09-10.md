# 手机布局第 1 步验证记录

范围：本地 `99chat` 前端与真实本地 OpenIM，2026-09-10。首次验证只实现响应式框架；后续 GitHub 推送与生产发布记录见文末。本功能没有重启 OpenIM。

## 实现

- <= 768px 单屏列表/详情；手机根导航顺序为通讯录、聊天、我的，详情隐藏底栏。桌面多栏保持。
- 手机 `/settings` 留在个人中心菜单；桌面仍进入资料。根路由尾部斜杠同样有效。
- 原有返回按钮复用，补齐设置根页与缺失资源的返回入口。
- 动态视口、安全区、短视口输入区、44px 主操作触控区域、气泡/媒体宽度和弹窗边界。
- 不改 OpenIM 初始化、登录、多端策略、权限、发送/上传与收藏 API。

## 复现与限制

在 `99chat` 目录依次执行两套 E2E，避免同一测试账号被并行测试干扰。默认连接本地 5199 与既有本地测试账号，可通过脚本中的 `E2E_*` 环境变量改为专用测试账号。聊天测试在这对账号间保留验证消息、图片与收藏；如果旧的好友生命周期测试删除了关系，会通过 UI 重新建立这对测试账号的好友关系。不得对客户账号运行。

- 尚未进行实体 iPhone/Android 软键盘、刘海/横屏与系统手势验收；缩小桌面浏览器高度不等于真机键盘。
- 本轮只验证媒体预览打开/关闭及操作入口可达，未重新验收所有媒体业务（例如多图前后切换、所有视频格式）。
- 群管理页仍能看到既存的成员名称后数字 `0`；它不由本次布局变更产生，留作独立业务/UI 修复，不宣称所有既知问题已解决。
- 首次本地验收时尚未发布；后续发布范围与线上回归见下。
